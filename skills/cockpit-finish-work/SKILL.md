# cockpit-finish-work · 本轮收尾

**何时用**：本轮的功能都验收通过，准备发布或结束这一轮时（对应 Trellis 的 finish-work）。

**目的**：把这一轮收干净：任务清零、验收签核、发布清单、留痕。

## 步骤
1. 只读确认 `.trellis/tasks/` 里本轮任务是否都 `completed`；还有在做/未开始的，列出来交给人决定（继续做还是挪到下一轮）。**不要替人改 Trellis 任务文件。**
2. 确认验收全绿并已签核（面板「验收签核」）。
3. 要发布就写 `release.json`（真实产物 + sha256 + 回滚说明），再请人点「发布批准」。
4. 写最后一条回执：`stage=release`（未发布则写当前阶段），摘要写清这一轮交付了什么。
5. 列出下一轮建议（不复用本轮范围，重新走需求定义）。

## 产出
- 收尾清单
- release.json（可发布时）
- 本轮最后一条回执

## 硬约束
- 不写 Trellis 文件
- 未签核不放行
- 不把"没做完"包装成"下轮再做"

> 这些命令是驾驶舱自己的流程实现：Trellis 只作为数据来源（`.trellis/tasks`、`.trellis/spec`、审核账本），**不调用 `trellis` CLI**。
