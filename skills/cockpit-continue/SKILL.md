# cockpit-continue · 断点续作

**何时用**：上次没做完、或换了一个会话要接着做（对应 Trellis 的 continue）。

**目的**：不靠记忆，靠账本恢复到断点。

## 步骤
1. 读最后 3 条回执：阶段、状态、摘要、`task_ref`、`write_scope`。
2. 读 `review.json` / 审核账本里最后一轮的未处置问题（有就必须先处置）。
3. 对照面板 `nextAction`：如果和最后一条回执的阶段不一致，以面板为准（说明状态已推进）。
4. 一句话说明「上次做到哪、为什么停、这次从哪继续」，然后继续做。
5. 做完写回执；`summary_for_human` 必须是一句人话。

## 产出
- 续作说明
- 新的执行回执

## 硬约束
- 不重复已完成的步骤
- 不跳过未处置的审核问题
- 不凭印象说"做完了"

> 这些命令是驾驶舱自己的流程实现：Trellis 只作为数据来源（`.trellis/tasks`、`.trellis/spec`、审核账本），**不调用 `trellis` CLI**。
