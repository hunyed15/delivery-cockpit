# dsh-project-cockpit

DSH 插件：把项目的真实状态收拢成一屏——**做到哪了、卡在哪、谁在干、下一步做什么用什么**。

它**接线**：把现成的 agent loop（DSH 内核）、现成的 skills/MCP、现成的会话与 worktree 连起来，
把人需要知道的信息抄到仪表上。**不复制 agent 的判断**：插件决定"干什么、什么时候、干完没有"，
agent 决定"怎么干、用哪个技能、失败怎么办"。

- **完整功能设计**：[docs/design.md](docs/design.md)
  - **初始化工作区**：一次显式操作，把规则与模板释放到 `.dsh/plugin-state/`（技能只登记不复制）
  - **执行回执** `receipts.jsonl`：任何技能跑完追加一行，1 个适配器通吃所有社区能力
  - **阶段能力路由 Playbook**：每阶段告诉 agent 可用哪些能力，agent 自主取舍
  - **自动驾驶 L0/L1/L2**：L1 人点一次即可自主跑；派活底座是 DSH 的 Agent Teams
  - **验效果**：验收表 JSON + 证据截图，`null` 永不等于 pass
- **实现状态**：见设计文档 §14 里程碑。本仓库目前只承载设计；实现代码暂在本地另一仓库，迁入前两边保持一致。
