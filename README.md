# dsh-project-cockpit

DSH 插件：把项目的真实状态收拢成一屏——**做到哪了、卡在哪、谁在干、下一步做什么用什么**。

读已有事实（trellis 任务、审核账本、会话状态、交卷小票），归一、投射、给出唯一动作；
不生产业务数据，不另存状态，也不自己编排技能执行（**是仪表盘，不是发动机**）。

- **完整功能设计**：[docs/design.md](docs/design.md)
  - 八步生命周期（含"初始化工作区"前置步）
  - 阶段能力路由 Playbook：每个阶段该用哪个社区 Skill/MCP
  - 交卷小票协议 `events.jsonl`：1 个适配器通吃所有社区能力
  - 验效果（验收表 + 截图）是 V1 闭环的一环，不是第二版
- **实现状态**：见设计文档 §13 里程碑。本仓库目前只承载设计；实现代码暂在本地另一仓库，迁入前两边保持一致。
