# dsh-project-cockpit

DSH 插件：把项目的真实状态收拢成一屏——**做到哪了、卡在哪、谁在干、下一步做什么**。

读已有工具产出的事实（trellis 任务、审核账本、会话状态），归一、投射、并给出唯一动作；
不生产业务数据，也不另存状态。

- **完整功能设计**：[docs/design.md](docs/design.md)（13 节，含一屏五区、四类事实、降级矩阵、里程碑）
- **实现状态**：见设计文档 §14。本仓库目前只承载设计；实现代码暂在本地 `D:\Coding\dsh-plugins\claude-code-review`，迁入前两边保持一致。
